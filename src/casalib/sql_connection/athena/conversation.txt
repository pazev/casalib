  A few things worth reviewing in the dialect:

  - enrich.sql: __other_N.* will include the join key columns from the right side — you may want to deduplicate
  those later in your pipeline.
  - jsonify.sql: Uses map_from_arrays which returns a Presto/Trino MAP<VARCHAR, VARCHAR>. If you need JSON
  string output instead, json_format(cast(map_from_arrays(...) AS JSON)) would work.
  - last_partitions.sql: The __latest CTE selects date_ingestion as well, so the join condition in _join_on
  (which only uses columns) must also include date_ingestion to correctly filter. Looking at the dialect code,
  join_on = _join_on(columns, ...) — this means you join only on the groupby columns, so the
  __latest.date_ingestion column is selected but not used in the ON clause. That's intentional — the MAX value
  is inferred via the join on the key columns only.
