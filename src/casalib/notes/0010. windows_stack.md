
My Windows Stack
================
1.  Basics
    -   Ensure %USERPROFILE%\bin is in the path
    -   Put several .bat there to quickly call programs with
        Windows+R, always with the template below:

            @echo off
            chcp 65001 >nul
            cd working_folder
            program %*

2.  Use selenium with Edge: easier to use logged in sites

3.  Programs to install (prefer the portable/zip
    installations)
    1. Conda + environment (use miniconda or miniforge)
    2. awscliv2 (install on user, add folder to USER PATH)
    3. git (ensure USER PATH)
    4. Bruno (API calls)
    5. vscode (use .bat, change user and extension folder)
    6. gnuwin32
        - Ensure the following programs (all available):
            bzip, gzip, tar, tree
    7. 7zip
        - Try to get the portable; if not, get the 7zip
            extras + msi, extract the msi to a folder,
            remove the '_' from 7zFM.exe and _7zG.exe
        - Run .reg file to add 7zip to context menu
            - Folder
            - File
